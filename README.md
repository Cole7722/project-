# Find That Book

A responsive, dependency-free book discovery app built with HTML, CSS, and JavaScript.

## Features

- Search up to 1000 popular books by title or author
- Filter by genre and curated collections
- Collections include popular picks, hidden gems, modern classics, recent reads, and highly rated books
- Select a book to view its description, publication year, genre, and reader rating
- Display real cover images with decorative fallback covers
- Responsive layout for desktop and mobile

## Run

Open `index.html` directly in a browser. The expanded catalogue loads live from Open Library.
