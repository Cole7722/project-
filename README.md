# Northwood Library Catalogue

A responsive, dependency-free library catalogue built with HTML, CSS, and JavaScript.

## Features

- Search books by title or author
- Filter by all, available, or on-loan books
- Toggle a book between available and on-loan
- Loan changes are saved in browser local storage
- Responsive layouts for desktop and mobile

## Run

Open `index.html` directly in a browser, or serve the folder with any static file server.
