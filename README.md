# Find That Book

Changed the title of the app and added book information.

A responsive, dependency-free book discovery app built with HTML, CSS, and JavaScript.

## Features

- Search 50 popular books by title or author
- Select a book to view its description
- Display publication year, genre, and Goodreads rating in the detail view
- Responsive layout for desktop and mobile
- No account, backend, or loan-state system

## Run

Open `index.html` directly in a browser, or use the VS Code **Open library catalogue** task.
